# Elaria IVF

Next.js (App Router) and Tailwind CSS website.

```
app/          routes (home, about, treatments, doctors, success-stories, blog, contact)
components/   UI, split by area (layout, home, about, treatments, doctors, stories, blog, contact, ui)
data/         category.json holds all static content for every page
types/        index.ts holds all TypeScript types
public/images photos and logo
```

Run it with `npm install` and then `npm run dev`.
